### 2.1 本轮（2026-06-06）Phase 3 交付明细

3 个提交（`6ef12f0` / `9e04406` / `d1bcca4`）：

- **interface**：新增 `protocol/dto.ts`（`UserInfo` / `WSState` 共享 DTO，单一真相源）。
- **runtime**：
  - `HttpClient`（axios）：请求拦截器在 Runtime 侧注入 token（永不跨 postMessage）、408/429/5xx 重试、`NETWORK_ERROR` 归一化。
  - `WebSocketManager`：单连接共享、指数退避重连、离线队列 FIFO 上限、channel/state 经 EventBus 派发（`ws:<channel>` / `ws:stateChanged`）。
  - `PostMessageRouter`：注册 `http:request`(`runtime.network`)、`ws:send`(`runtime.websocket`)、`ws:state`；桥接 `auth:userChanged` / `auth:permissionsChanged`。
- **core**：6 个 SDK 模块（薄包装 Client）+ `Client.id` getter（plugin 模块据此过滤自身可见性事件）；新模块覆盖率 100%。

## 4. 总体判断

- **地基与中段已成型**：Phase 1/2/3 + Phase 5 均达到「能加载、能通讯、能签名校验、插件能调用服务 API」的可用程度，类型与测试质量高（488 用例全绿、90% 覆盖门槛、协议单一真相源贯彻良好）。
- **剩余主战场**：Phase 4（UI 组件库）、Phase 3.5（System UI）、Phase 3.6（Exports/RPC），以及工程化（build/发布、samples、size 守护）。
- **粗略完成度估算**：约 **62–68%**（相较 6/6 上一轮约 45–50%，本轮 Phase 3 落地是主要增量）。
